# Double Digit Calculator using AT89C51

## Overview
Designed and implemented a double-digit calculator using the AT89C51 microcontroller, a 4×4 keypad, and a 16×2 LCD. The calculator performs basic arithmetic operations including addition, subtraction, multiplication, and division using embedded C programming.

## Components Used
- AT89C51 Microcontroller
- 4×4 Matrix Keypad
- 16×2 LCD
- Power Supply

## Features
- Double-digit arithmetic
- LCD output display
- Matrix keypad input
- Embedded C implementation

## Working Principle
The keypad accepts numerical input, which is processed by the AT89C51 microcontroller. The selected arithmetic operation is performed, and the result is displayed on the LCD.
